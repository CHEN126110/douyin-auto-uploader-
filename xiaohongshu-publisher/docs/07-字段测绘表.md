# 小红书千帆商品创建页 — 字段测绘表（第一版，2026-10-10）

**证据等级**：`verified` = 真机实测可见/文案确认；`candidate` = 合理推断待验证；`unknown` = 未读到，不许猜。
**阶段划分来自真机**：类目选中并点「下一步」后，同页展开五块——
`类目信息 / 基础信息 / 图文信息 / 价格库存 / 服务信息`（`verified`）。
⚠️ 注意：官方教学说的四组是"基础/销售/图文/服务"，**真机把"销售信息"叫「价格库存」** —— 以真机为准。

## 0. 解锁顺序（硬顺序，`verified`）

```
① 上传图片（素材空间抽屉 → 「上传本地图片」→ DOM.setFileInputFiles）
② 填商品标题（原生 setter + input/change；16–60 字符＝8–30 个字，汉字计 2）
③ 失焦（blur）→ 类目区块出现
④ 选中类目（**必须先关掉素材空间抽屉**，否则全屏遮罩挡住一切点击 → 纪律 4）
⑤ 点「信息已确认，下一步」→ 四组信息展开（点按钮要取**最小**匹配元素，取大的会点到动作栏容器）
```
