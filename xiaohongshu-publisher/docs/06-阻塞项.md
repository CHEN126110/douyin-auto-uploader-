  `E-XHS-DRAWER-CLOSED-AND-GATED-20261010`；复现

- **连锁影响（为什么它卡住整条线）**：

  **本工具不代做、不绕过**（属店铺资质与平台审核，不是可自动化的环节）。
- **解除判据（可验证）**：类目搜索/智能推荐里出现**不带「(未开通)」**的袜子类目，

## 已证伪的假设（保留，避免重复踩）

- ✗「标题框的 placeholder 是标题提示」→ 实测是**轮换提示**，且顶部还有一个同样轮换的帮助框；
  真正的标题框 placeholder 是**品牌前缀说明**（含「品牌」二字）。
- ✗「从 `N/60` 计数器往上爬祖先能定位标题框」→ 计数器与输入框**不在同一 DOM 分支**。
- ✗「合成 `element.click()` 能点开上传入口 / 展开菜单」→ 无效，必须真实鼠标事件。
- ✗「`Input.insertText` / 按键模拟能填表单」→ 无效，必须原生 setter + input/change。
- ✗「点『下一步』无反应是因为坐标超出视口」→ 实测 `top=1230 < vh=1278`，真因是
  **素材空间抽屉页脚盖在上面**（`elementFromPoint` 命中 `div.d-drawer-footer`）。
- ✗「点遮罩 / 按 Esc 能关掉素材空间抽屉」→ 都关不掉，只有点**抽屉自己的「取消」**有效。
- ✗「上传后素材列表『共 0 条』说明上传失败」→ 上传**成功**；正确判据是
  「本次共成功上传 N 个文件，M 个文件上传失败」。
