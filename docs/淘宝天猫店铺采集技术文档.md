# 淘宝/天猫店铺商品采集技术文档

## 一、概述

### 目标
在用户登录淘宝后，**完全通过协议/API 方式采集店铺全部商品信息**，不操作浏览器 DOM、不滚动页面、不触发反爬验证码。

### 最终成果
✅ **100% 纯协议采集** —— 零页面跳转、零 DOM 操作、零滚动

---

## 二、技术架构演进

### 阶段1：传统 DOM 采集（已废弃）
```
page.get(店铺URL) → 滚动页面 → 查找 <a href> 链接 → 逐个跳转单品页 → DOM提取
```
**问题**：新版淘宝店铺是 React SPA，无 `<a href>` 链接，频繁跳转触发反爬验证码。

### 阶段2：mtop API 发现
通过 CDP 协议拦截页面网络请求，发现了淘宝的 mtop API 体系：
- 端点：`h5api.m.taobao.com/h5/mtop.taobao.shop.simple.item.fetch/1.0/`
- 认证：MD5 签名 = `MD5(_m_h5_tk + '&' + timestamp + '&' + appKey + '&' + data)`
- 返回：商品列表（标题、主图、SKU、销量、链接）

### 阶段3：签名与反爬对抗（耗时最长）
| 尝试 | 方式 | 结果 | 原因 |
|------|------|------|------|
| 1 | Python HTTP POST mtop | ❌ RGV587 | TLS 指纹被检测 |
| 2 | `lib.mtop.request()` 浏览器调用 | ❌ UNEXCEPT | 页面未"激活" |
| 3 | Python 签名 + 浏览器 XHR | ❌ ILLEGAL | 反爬 token 缺失 |
| 4 | CDP 拦截页面自然请求 | ⚠️ 可用 | 需要滚动触发渲染 |
| **5** | **CDP token + Python 签名 + 浏览器 fetch()** | **✅** | **TLS指纹正确 + 签名正确** |

### 阶段4：单品价格获取
mtop 返回的 `discountPrice` 是 WASM 字体编码（如 `[1_7ij1w4tp#51#base64#]`），无法直接使用。

经过大量探索后发现的最终方案：
- 单品页 SSR HTML 中包含 `__ICE_APP_CONTEXT__` JSON 对象
- 该对象内含 **未编码的真实价格**（`priceMoney: "1680"` → ¥16.80）
- 用 **Python HTTP + 浏览器 Cookies** 请求单品页 HTML，提取 ICE JSON
- 无需浏览器导航，无 CORS 限制

## 三、最终架构

```
用户登录淘宝
     │
     ├── 步骤1: mtop 商品列表
     │   ├─ CDP 提取 _m_h5_tk token
     │   ├─ Python MD5 签名
     │   ├─ 浏览器 fetch() 发送请求
     │   └─ 获得: 标题/主图/SKU/销量/链接
     │
     ├── 步骤2: 单品价格提取 (零跳转!)
     │   ├─ CDP 提取完整浏览器 Cookies
     │   ├─ Python HTTP GET 单品页HTML
     │   ├─ 括号计数法提取 ICE JSON
     │   └─ 获得: 价格/多图/完整SKU
     │
     └── 步骤3: 图片下载
         ├─ Python HTTP 下载主图(3:4 + 1:1)
         ├─ SKU 图片
         └─ 详情页图片
```

```python
import hashlib

app_key = '12574478'
data = '{"shopId":"166016382","sellerId":"2939138290","page":"1","pageSize":"30"}'
token = '从CDP提取的_m_h5_tk前半部分'
timestamp = str(int(time.time() * 1000))

sign = hashlib.md5(f'{token}&{timestamp}&{app_key}&{data}'.encode()).hexdigest()
```

### 4.3 ICE JSON 提取（括号计数法）
```python
def extract_ice_json(html):
    """从单品页HTML提取 __ICE_APP_CONTEXT__ JSON"""
    idx = html.find('__ICE_APP_CONTEXT__')
    rest = html[idx:]
    b_match = re.search(r'var\s+b\s*=\s*\{', rest)
    start = idx + b_match.end() - 1  # 指向 {
    
    # 括号计数，处理嵌套JSON
    depth = 0
    in_string = False
    escape = False
    for i in range(start, len(html)):
        ch = html[i]
        if escape: escape = False; continue
        if ch == '\\': escape = True; continue
        if ch == '"' and not escape: in_string = not in_string; continue
        if in_string: continue
        if ch == '{': depth += 1
        elif ch == '}':
            depth -= 1
            if depth == 0:
                return html[start:i+1]
    return None
```

### 4.5 图片 1:1 方图转换
```python
def _to_square_url(img_url, size=800):
    """阿里CDN图片URL → 1:1方图"""
    cleaned = str(img_url)
    # 剥离CDN处理后缀
    cleaned = re.sub(r'_\.webp$', '', cleaned)
    cleaned = re.sub(r'\.webp$', '', cleaned)
    cleaned = re.sub(r'_q\d+\.jpg_?$', '', cleaned)
    # 添加方图裁剪后缀
    return f'{cleaned}_{size}x{size}xz.jpg'
```

## 五、发现的重要数据入口

| 发现 | 位置 | 价值 |
|------|------|------|
| mtop API | `h5api.m.taobao.com` | 商品列表(标题/SKU/销量) |
| `__ICE_APP_CONTEXT__` | 单品页 SSR HTML | **未编码价格+原图** |
| `_m_h5_tk` cookie | CDP Network.getAllCookies | mtop 签名 token |
| `secfont1` FontFace | document.fonts | 价格字体(未使用) |
| `.text-price` CSS类 | 页面样式 | 激活字体动画 |
| `g_config.seller` | 店铺页 JS 全局变量 | 店铺ID/卖家ID |

## 六、验证码处理策略

| 场景 | 处理 |
|------|------|
| 店铺页触发验证 | 等待用户手动完成(120s)，通过后自动继续 |
| 单品采集触发验证 | 同上 + 连续3次暂停30s |
| 采集间隔 | 可配置(默认3s，已验证1s可行) |
| 浏览器 Profile 复用 | 登录态持久化，减少重复登录 |

```
├── title            : 标题 (mtop)
├── price            : {current, original, currency}
├── main_images[]    : 主图 (ICE原图 + 1:1方图)

├── url              : 商品链接

```

## 八、已知限制

1. **单品详情图**：ICE 中不含详情图，当前版本未采集
2. **登录依赖**：首次使用需要用户在采集浏览器中手动登录淘宝
3. **Cookie 有效期**：_m_h5_tk 有时效性，过期需重新提取
4. **sefont 价格解码**：理论可行(DOM截图+像素匹配)，但复杂度高未实施
