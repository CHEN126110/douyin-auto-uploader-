# Douyin 平台错误处理手册

## 一、前端表单验证错误（DOM流水线）

### 图片类

| 错误信息 | 触发条件 | 自动处理 | 用户处理 |
|----------|----------|----------|----------|
| 错误长宽比需为1:1 | 白底图非正方形 | **AI去背景工具**（平台自动弹出，CDP可点击确认） | 上传1:1白底图 或 使用AI工具 |
| 错误长宽比需为1:1 | 主图非正方形 | 平台自动裁剪工具 | 采集时下载1x1版本 |
| 主图视频质量不合格 | 无视频/视频不清晰/主体未出镜 | 无自动工具 | 可跳过（非必填） |
| 上传后在频道、活动等场景使用 | 信息提示 | - | 无需处理 |

### 价格库存类

| 错误信息 | 触发条件 | 自动处理 | 用户处理 |
|----------|----------|----------|----------|
| 错误价格最小应为0.01 | SKU价格=0或未设置 | ❌ | 通过`calculate_smart_prices`设置 |
| 库存不能为空 | 库存未填写 | ❌ | 填写repo字段 |

### SKU/规格类

| 错误信息 | 触发条件 | 自动处理 | 用户处理 |
|----------|----------|----------|----------|
| 规格型号未成功确认规格值 | 规格组合不完整 | ❌ | 检查spec_detail配置 |
| 重复SKU名称 | 多个SKU同名 | ❌ 前端验证拦截 | 去重合并SKU |

### 类目属性类

| 错误信息 | 触发条件 | 自动处理 | 用户处理 |
|----------|----------|----------|----------|
| 请选择，最多选5项 | 属性选项超限 | ❌ | 减少选择或使用默认值 |
| 找不到合适的属性/属性值？点击反馈 | 属性值不匹配 | ❌ | 选择其他兼容值 |

### 资质类

| 错误信息 | 触发条件 | 自动处理 | 用户处理 |
|----------|----------|----------|----------|
| 合格证 | 缺合格证资质 | ❌ | 上传合格证图片 |
| 质检报告 | 缺质检报告 | ❌ | 可选（仅特定类目） |

## 二、API 提交错误（协议流水线）

### 重要: code=10013 是通用验证错误

`code=10013` 不是单一的 "token非法" 错误。平台使用这个 code 返回多种不同的验证错误，**具体原因在 msg 字段**。以下是根据实测整理的完整映射：

| msg 关键词 | 实际含义 | 错误码 | 修复 |
|------------|----------|--------|------|
| 发品方式可能存在异常/非官方途径 | 反滥用拦截 (账号级, 持续数小时) | ERR_ANTI_ABUSE_BLOCK | 等待冷却 + 降低频率 |
| 商品标题最长不能超过30个汉字 | 标题超过30汉字/60字符 | ERR_BODY_TITLE_TOO_LONG | 缩短标题 |
| 提交参数异常 token非法 | 认证字段缺失 (n_token/shop_id/feature) | ERR_AUTH_TOKEN_INVALID | 检查 body 构建 |
| 主图3：4比例要求3:4 | 3:4主图比例不合规 | ERR_IMAGE_RATIO_34 | 使用 PIL 中心裁剪 |
| 主图1:1比例要求1:1 | 白底图/1:1主图比例不合规 | ERR_IMAGE_RATIO_11 | 使用 PIL 裁剪正方形 |
| 请上传1~5张商品主图 | 主图数量不足 | ERR_IMAGE_COUNT | 上传至少1张主图 |
| 价格/price | 价格验证失败 (具体看msg) | ERR_PRICE_TOO_LOW / ERR_BODY_MISSING_PRICE | 调整价格 |
| SKU/sku/规格 | SKU或规格问题 (具体看msg) | ERR_SKU_DUPLICATE / ERR_SPEC_MISMATCH | 检查SKU配置 |

### 反滥用机制 (新发现)

| 现象 | 原因 | 恢复方式 |
|------|------|----------|
| 连续5-7次成功后, 所有提交返回反滥用msg | 平台检测到高频/非人工发品模式 | 等待数小时冷却 + 通过页面手动发布一次 |
| 页面刷新后仍被拦截 | 账号级别封锁, 非session级别 | 无法立即恢复, 需等待 |
| 草稿模式 (check_status=0) 也触发 | 反滥用检测不看check_status | 与发布模式无关 |

### 提交频率建议

| 场景 | 推荐频率 |
|------|----------|
| 测试/调试 | 每次间隔 ≥ 60秒, 一天内 ≤ 10次 |
| 生产环境 | 每次间隔 ≥ 2分钟, 建议通过抖店开放平台 API |
| 超过限制 | 触发反滥用 → 等待 2-6 小时后恢复 |

### 参数类

| code | msg | 原因 | 处理 |
|------|-----|------|------|
| 500 | 类目ID必传/不符合平台规则 | getSchema缺category_id或类目无效 | 传入正确的category_leaf_id |

## 三、平台自动处理工具

| 工具 | 触发条件 | DOM调用方式 | 协议替代 |
|------|----------|-------------|----------|
| AI白底图去背景 | 上传非1:1白底图时弹出 | CDP点击弹窗中的确认按钮 | 提前用1:1主图作为白底图 |
| 智能裁剪主图 | 上传非1:1主图时 | 自动裁剪 | batchupload后平台自动处理 |
| 从1:1主图智能裁剪 | 有1:1图但缺白底图 | CDP点击按钮 | 直接上传1:1主图作为白底图 |
| 从主图填入 | 类目属性预填 | CDP点击按钮 | 协议中直接填入属性值 |

## 四、质量分相关

| 指标 | 影响 | 改进方式 |
|------|------|----------|
| 主图视频缺失 | 扣分（非必填） | 可选上传 |
| 白底图质量 | 影响搜索结果展示 | 确保1:1白色背景 |
| 商品信息完整度 | 低于85分限制搜索流量 | 尽可能填写可选属性 |

## 五、协议流水线结构化错误码 (protocol-research/fxg_errors.py)

### 错误响应格式

```json
{
  "success": false,
  "error": {
    "code": "ERR_CDP_NO_BROWSER",
    "category": "cdp",
    "message": "无法连接到Chrome调试端口 (端口: 9222)",
    "fix_hint": "请使用 --remote-debugging-port=9222 启动Chrome",
    "retryable": false,
    "detail": "..."
  },
  "steps": [
    {"name": "get_session", "status": "failed", "elapsed_ms": 12, "summary": "..."}
  ]
}
```

### 各步骤错误码

| 步骤 | 错误码 | 类别 | 消息 | 可重试 |
|------|--------|------|------|--------|
| get_session | ERR_CDP_NO_BROWSER | cdp | 无法连接Chrome调试端口 | 否 |
| get_session | ERR_CDP_NO_PAGE | cdp | 未找到jinritemai.com标签页 | 否 |
| get_session | ERR_CDP_WEBPACK_CHUNK | cdp | 未找到webpack chunk | 否 |
| get_session | ERR_AUTH_NO_COOKIE | auth | 未获取登录Cookie | 否 |
| get_session | ERR_AUTH_NO_PUBLISH_ID | auth | 无法生成publishId | 否 |
| get_schema | ERR_SCHEMA_FAILED(500) | schema | 类目ID无效/不符合平台规则 | 否 |
| get_schema | ERR_SCHEMA_EMPTY | schema | Schema返回为空 | 否 |
| upload_images | ERR_IMAGE_NOT_FOUND | input | 图片文件不存在 | 否 |
| upload_images | ERR_IMAGE_UPLOAD_FAILED | network | 图片上传失败(Cookie/网络) | 是 |
| build_body | ERR_BODY_MISSING_TITLE | input | 标题<8字符 | 否 |
| build_body | ERR_BODY_MISSING_CATEGORY | input | 缺少类目配置 | 否 |
| build_body | ERR_BODY_INVALID_SKU | validation | SKU列表为空 | 否 |

## 六、采集→导入阶段的预防措施

| 检查项 | 采集时处理 | 导入时处理 |
|--------|-----------|-----------|
| SKU去重 | mtop skuInfoList按名称合并 | `import_capture_result`中按name去重 |
| SKU定价 | 采集时price=0 | 导入后自动调`calculate_smart_prices` |
| 类目推断 | 解析标题/分类 | 自动设clazz |
| 主图比例 | 同时下载3:4和1:1 | 按800/750目录结构保存 |
| 白底图 | 第一张1:1主图 | 标记为白底图候选 |
| 详情图 | page.get()获取 | 保存到详情页目录 |
