# 抖音平台错误/提示 完整映射表

## 一、表单验证错误（客户端）

| 错误信息 | 触发条件 | 自动处理 | 需用户介入 |
|----------|----------|----------|-----------|
| `错误长宽比需为1:1` | 白底图非正方形 | 自动裁剪为1:1，或从主图中选1:1图 | - |
| `错误价格最小应为0.01` | SKU价格为0或空 | 自动调用 calculate_smart_prices | - |
| `请选择，最多选5项` | 多选项超过限制 | 自动选前5项 | - |
| `找不到合适的属性/属性值？点击反馈` | 属性值不匹配 | 跳过该属性 | 特殊属性需手动 |
| `长宽比需为1:1` | 主图非正方形 | 使用1:1版本主图 | - |
| 品牌下拉无"无品牌"选项 | 品牌必填但无默认 | 自动选第一项(商品级/无品牌) | - |
| 规格值重复 | SKU名称重复 | **导入前去重** | 确认合并逻辑 |
| 规格型号未成功确认规格值 | SKU配置不完整 | 补全spec_detail | - |

## 二、平台AI工具（可自动调用）

| 工具 | 触发场景 | 调用方式 |
|------|----------|----------|
| AI白底图生成 | 上传非白底图时弹出 | CDP点击"智能裁剪"按钮 → 等待AI处理 |
| 主图智能裁剪 | 3:4图需1:1裁剪 | CDP点击"从1:1主图智能裁剪" |
| 标题智能生成 | 标题为空 | 可跳过(前端自动生成) |

## 三、API提交错误（服务端）

| code | 错误信息 | 原因 | 处理 |
|------|----------|------|------|
| 10013 | `提交参数异常 token非法` | 缺少CSRF/认证token | 从页面提取__token，从context提取n_token |
| 500 | `类目ID必传` | getSchema缺少category_id | 补全context.category_id |
| 10001010A | `系统检测到发品方式异常` | Python HTTP直发被检测 | 改用浏览器fetch()或webpack post() |

## 五、提交后质量提示（非阻塞）

| 提示 | 影响 |
|------|------|
| `商品信息质量良好90` | ✅ 达标 |
| `质量分低于85分会造成搜索流量受限` | ⚠️ 需优化 |
| `主图视频质量不合格` | ⚠️ 建议补充视频 |
| `商品提交成功，需审核通过后生效` | ℹ️ 正常流程 |
| `审核周期为1-2个工作日` | ℹ️ 正常流程 |

## 六、错误处理策略

```
客户端验证错误 → 自动修复(图片/价格/去重) → 重试
     ↓ (无法自动修复)
  提示用户手动处理 → 用户确认 → 继续
  
API错误 → 重新获取token → 重试1次
     ↓ (仍失败)  
  回退到DOM流水线
```
