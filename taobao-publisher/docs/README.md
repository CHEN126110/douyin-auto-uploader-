## 阅读建议

- **先整理发布资料** → 读 `09`；它汇总了现有画面与当前代码的边界。

- **要动手改代码** → 先读 `../AGENTS.md`，再读 `04`（安全门），再读 `03`（设计）。
- **要加字段或选择器** → 读 `../contracts/README.md` + `05`（证据日志）。
- **想知道为什么发不出去** → 读 `01` §1 + `02` §3 + `06` B-01。
- **想接着往下做** → 读 `07`。

## 文档里的约定

- 结论一律标注证据等级：**【实证】/【推断】/【未知】/【已排除】**。
- 外部资料给可点击链接；**用户投稿、第三方博客不作为官方口径**（例如
  「ISV 保证金 10-15 万」这类数字本子项目未采信）。
- 数字（数量 / 尺寸 / 长度限制）一律落在 `../contracts/rules.json`，不写死在文档里当权威。
