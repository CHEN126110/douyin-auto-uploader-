# protocol-research-clean-20260505 工作约束

本目录是独立协议研究区，用于重新梳理抖店发布页接口和自动化替代路径。

## 基本原则

- 只在本目录内新增研究文档、脚本和去敏产物。
- 不直接改正式上传流水线，不接入 `POST /api/upload/start`。
- 不把旧研究目录里的结论直接当作本目录结论；旧产物只能作为参考线索，必须重新实证。
- 不保存 cookie、token、手机号、店铺敏感信息、完整签名 URL 或未脱敏请求头。
- 不做登录绕过、验证码绕过、风控绕过、平台权限绕过或高频探测。
- 不使用兜底代码掩盖字段映射错误；字段缺证据时必须记录为 blocker。

## 编码与路径

- 文件默认使用 UTF-8。
- 新增脚本、目录、产物文件名优先使用 ASCII。
- PowerShell 命令运行前设置：

```powershell
[Console]::OutputEncoding=[System.Text.Encoding]::UTF8
$OutputEncoding=[System.Text.Encoding]::UTF8
```

## 研究收口要求

每轮研究至少要产出以下一种结果：

- 缩小一个关键不确定性。
- 证明一个接口或字段是已实证、候选、阻塞或排除。
- 形成可复跑的只读探针或离线分析脚本。
- 给出能否进入阶段性自动化执行器的明确判断。
